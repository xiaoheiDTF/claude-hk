# 999-2-git-push

Use this skill when the user wants both a commit and a push.

Rules:
1. Review the diff before staging anything.
2. Stage related changes in logical groups.
3. Commit locally first, then push only after the commit is complete.
4. Do not push unrelated or accidental changes.
