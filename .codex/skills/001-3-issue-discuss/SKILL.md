# 001-3-issue-discuss

Use this skill when an issue needs discussion, clarification, or iterative refinement.

Rules:
1. Update the issue thread with clear comments before making large changes.
2. Summarize decisions, open questions, and next actions in the issue body or comments.
3. Keep discussion notes in the repo when the workflow expects a local record.
