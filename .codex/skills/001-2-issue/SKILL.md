# 001-2-issue

Use this skill when creating or managing GitHub issues for this repo.

Rules:
1. Draft issues locally under `doc/issues/drafts/` before publishing.
2. Templates live under `doc/issues/templates/`.
3. Keep labels consistent with the repo's `labels.conf`.
4. Prefer `gh issue` commands for publishing, viewing, and listing issues.
5. Keep a local draft after publishing and append the published URL or issue number.
