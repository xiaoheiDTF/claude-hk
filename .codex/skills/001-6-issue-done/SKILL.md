# 001-6-issue-done

Use this skill when the implementation for an issue is complete and ready for PR work.

Rules:
1. Confirm the branch matches the issue.
2. Make sure there are no uncommitted changes that should be included first.
3. Update the issue with a completion note and prepare it for the PR step.
