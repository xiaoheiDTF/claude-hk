## 架构设计

```
.claude/
├── hooks/
│   ├── base.sh            # 核心: source platform.sh → 读stdin → 解析 → 日志 → 输出
│   ├── platform.sh        # 平台检测: OS、Python路径、工具兼容性
│   ├── json_get.py        # JSON解析 (全平台, 纯stdlib)
│   ├── init.sh            # 初始化: 检测环境 → 下载Python → 写标记
│   ├── .initialized       # 标记文件 (JSON格式, 记录平台/版本/时间)
│   ├── logs/              # 日志目录
│   └── 01-xx/base.sh      # 29个钩子 (不变)
├── python/                # 嵌入Python (gitignored)
│   ├── python.exe         # Windows embeddable
│   └── bin/python3        # Linux/Mac symlink
└── settings.json          # 钩子注册
```

### 调用链

```
SessionStart / Setup 事件
  → init.sh (检查 .initialized 是否存在)
    → 不存在 → 检测平台 → 配置Python → 写 .initialized
    → 存在 → 跳过

每个钩子事件
  → xx/base.sh
    → source ../platform.sh  (设置 OS_TYPE, PYTHON_CMD 等)
    → source ../base.sh      (读stdin, 解析JSON, 日志)
    → 执行具体逻辑
    → hook_output
```

## Issue #1: 跨平台适配

### 设计: `platform.sh`

```bash
#!/bin/bash
# 从当前项目中提取的平台检测逻辑

# ---- 检测操作系统 ----
detect_os() {
  case "$(uname -s)" in
    Linux*)   echo "linux" ;;
    Darwin*)  echo "macos" ;;
    MINGW*|MSYS*|CYGWIN*) echo "windows" ;;
    *)        echo "unknown" ;;
  esac
}

OS_TYPE=$(detect_os)

# ---- Python 路径 (按平台) ----
# Windows: .claude/python/python.exe (嵌入版)
# Linux/Mac: .claude/python/bin/python3 (如有) → 系统 python3
resolve_python() {
  local project_python
  case "$OS_TYPE" in
    windows) project_python="$CLAUDE_PROJECT_DIR/.claude/python/python.exe" ;;
    *)       project_python="$CLAUDE_PROJECT_DIR/.claude/python/bin/python3" ;;
  esac
  # 1. 优先项目自带
  if [ -x "$project_python" ]; then echo "$project_python"; return; fi
  # 2. 系统 Python (验证可用)
  for cmd in python3 python; do
    if command -v "$cmd" &>/dev/null && "$cmd" -c "pass" 2>/dev/null; then
      echo "$cmd"; return
    fi
  done
  echo ""
}

PYTHON_CMD=$(resolve_python)

# ---- 兼容日期格式 ----
# macOS date 不支持 +%F，统一用 +%Y-%m-%d
DATE_TODAY=$(date +%Y-%m-%d)
```

### 从 base.sh 中提取的改造

当前 `base.sh` 中的 `_find_python` 和 `EMBED_PYTHON` 逻辑 → 移入 `platform.sh`

`base.sh` 改为:
```bash
source "$HOOKS_DIR/platform.sh"   # 新增: 平台感知
# 删除 _find_python / EMBED_PYTHON / _PY_CMD 相关代码
# json_get 中直接使用 $PYTHON_CMD
```

## Issue #2: Python 环境与用户配置

### 策略: 按平台分级处理

| 平台 | 方案 | 依赖 |
|------|------|------|
| Windows | 下载 embeddable package → `.claude/python/` | 无需系统Python |
| Linux | 系统 `python3` 通常已安装; 备选: 下载 standalone python | 大部分已有 |
| macOS | 系统 `python3` (Xcode CLI Tools); 备选: brew python3 | 大部分已有 |

`_find_python` 的验证逻辑（`$cmd -c "pass" 2>/dev/null`）→ 移入 `platform.sh` 的 `resolve_python()`

## Issue #3: 初始化与配置化

### 设计: `init.sh`

```bash
#!/bin/bash
# 首次运行初始化脚本

HOOKS_DIR="$CLAUDE_PROJECT_DIR/.claude/hooks"
INIT_MARKER="$HOOKS_DIR/.initialized"

# 已初始化 → 跳过
[ -f "$INIT_MARKER" ] && exit 0

# ---- 检测平台 ----
source "$HOOKS_DIR/platform.sh"

# ---- 配置 Python ----
setup_python() {
  # 如果已有可用 Python → 不需要下载
  [ -n "$PYTHON_CMD" ] && return 0

  case "$OS_TYPE" in
    windows) download_windows_python ;;
    linux|macos)
      echo "ERROR: 未找到 python3，请安装后重试"
      echo "  macOS: xcode-select --install 或 brew install python3"
      echo "  Linux: sudo apt install python3 或 sudo yum install python3"
      return 1
      ;;
  esac
}

download_windows_python() {
  local python_dir="$CLAUDE_PROJECT_DIR/.claude/python"
  local url="https://www.python.org/ftp/python/3.13.9/python-3.13.9-embed-amd64.zip"
  local zip_file="$python_dir/python-embed.zip"

  mkdir -p "$python_dir"
  echo "正在下载 Python 嵌入版..."
  curl -L -o "$zip_file" "$url" && \
    cd "$python_dir" && unzip -o "$zip_file" && rm "$zip_file"
}

# ---- 执行 ----
if setup_python; then
  # 写入标记文件
  cat > "$INIT_MARKER" <<EOF
{
  "os": "$OS_TYPE",
  "python": "$PYTHON_CMD",
  "initialized_at": "$(date +%Y-%m-%dT%H:%M:%S)"
}
EOF
fi
```

### 触发方式

利用已有的 `SessionStart` 和 `Setup` 事件:

在 `01-session-start/base.sh` 中加入:
```bash
# 首次运行 → 触发初始化
[ ! -f "$HOOKS_DIR/.initialized" ] && bash "$HOOKS_DIR/init.sh"
```

### 优雅降级

如果初始化失败（无Python、网络不通）:
- hooks 以 exit 0 退出（非阻止）
- 日志记录 WARN
- 不影响 Claude Code 正常使用
