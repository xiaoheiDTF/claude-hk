# 初始化与配置化问题

## 问题描述

项目目前缺少首次使用的初始化机制。用户克隆仓库后，hooks 直接运行会因为缺少 Python 环境而全部失败。需要实现首次运行检测和自动配置。

## 需要实现

### 首次运行检测

- 每次钩子脚本执行时，检查 `.claude/python/python.exe`（或 Unix 下的 python3）是否存在
- 如果不存在，触发初始化流程

### 初始化流程（仅 hooks 相关）

1. **检测平台**：Windows / Linux / macOS
2. **配置 Python 环境**：
   - Windows：下载 Python embeddable package 到 `.claude/python/`
   - Linux/macOS：检测系统 `python3`，不存在则提示安装
3. **验证**：运行 `python -c "import json; print('ok')"` 确认可用
4. **写入标记文件**：`.claude/hooks/.initialized` 防止重复初始化
5. **失败处理**：输出友好的错误信息到日志，hooks 以非阻止方式退出（exit 0）

### 配置状态检查

```
.claude/hooks/.initialized    — hooks 已初始化标记
.claude/python/python.exe     — Windows 嵌入 Python
.claude/hooks/logs/           — 日志目录
.claude/hooks/json_get.py     — JSON 解析脚本
```

## 优先级

当前只需要处理 hooks 的初始化配置化，其他组件后续再加。
