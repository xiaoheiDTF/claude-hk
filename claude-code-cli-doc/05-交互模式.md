# 交互模式

> 来源: https://code.claude.com/docs/zh-CN/interactive-mode

本文档涵盖 Claude Code 的键盘快捷键、Vim 模式、命令历史、后台 bash、提示建议等交互技巧。

---

## 键盘快捷键

### 常规控制

| 快捷键 | 描述 |
|--------|------|
| `Ctrl+C` | 取消当前输入或生成 |
| `Ctrl+X Ctrl+K` | 终止所有后台代理。在 3 秒内按两次以确认 |
| `Ctrl+D` | 退出 Claude Code 会话 |
| `Ctrl+G` 或 `Ctrl+X Ctrl+E` | 在默认文本编辑器中打开提示或自定义响应 |
| `Ctrl+L` | 重绘屏幕。强制完整的终端重绘 |
| `Ctrl+O` | 切换转录查看器。显示详细的工具使用和执行情况 |
| `Ctrl+R` | 反向搜索命令历史 |
| `Ctrl+V` / `Cmd+V`（iTerm2）/ `Alt+V`（Windows） | 从剪贴板粘贴图像 |
| `Ctrl+B` | 后台运行 bash 命令和代理。Tmux 用户按两次 |
| `Ctrl+T` | 切换任务列表 |
| `Left/Right arrows` | 在对话框选项卡之间循环 |
| `Up/Down arrows` 或 `Ctrl+P`/`Ctrl+N` | 移动光标或导航命令历史 |
| `Esc` + `Esc` | 回退或总结（checkpointing） |
| `Shift+Tab` 或 `Alt+M` | 循环权限模式 |
| `Option+P`（macOS）/ `Alt+P`（Windows/Linux） | 切换模型 |
| `Option+T`（macOS）/ `Alt+T`（Windows/Linux） | 切换扩展思考 |
| `Option+O`（macOS）/ `Alt+O`（Windows/Linux） | 切换快速模式 |

### 文本编辑快捷键

| 快捷键 | 描述 |
|--------|------|
| `Ctrl+A` | 将光标移动到当前行的开始 |
| `Ctrl+E` | 将光标移动到当前行的末尾 |
| `Ctrl+K` | 删除到行尾（存储已删除的文本以供粘贴） |
| `Ctrl+U` | 从光标删除到行首（存储已删除的文本） |
| `Ctrl+W` | 删除上一个单词（存储已删除的文本） |
| `Ctrl+Y` | 粘贴已删除的文本 |
| `Alt+Y`（在 `Ctrl+Y` 之后） | 循环粘贴历史 |
| `Alt+B` | 将光标向后移动一个单词 |
| `Alt+F` | 将光标向前移动一个单词 |

### 多行输入技巧

| 方法 | 快捷键 | 上下文 |
|------|--------|--------|
| 快速转义 | `\` + `Enter` | 在所有终端中工作 |
| Option 键 | `Option+Enter` | 在 macOS 上启用将 Option 作为 Meta 后 |
| Shift+Enter | `Shift+Enter` | 在 iTerm2、WezTerm、Ghostty、Kitty、Warp、Apple Terminal、Windows Terminal 中开箱即用 |
| 控制序列 | `Ctrl+J` | 在任何终端中工作，无需配置 |
| 粘贴模式 | 直接粘贴 | 对于代码块、日志 |

### 快速命令前缀

| 前缀 | 描述 |
|------|------|
| `/` 在开始 | 命令或 skill |
| `!` 在开始 | Shell 模式：直接运行命令并将执行输出添加到会话 |
| `@` | 文件路径提及：触发文件路径自动完成 |

### 转录查看器快捷键

当转录查看器打开时（使用 `Ctrl+O` 切换）：

| 快捷键 | 描述 |
|--------|------|
| `Ctrl+E` | 切换显示所有内容 |
| `[` | 将完整对话写入终端的原生滚动缓冲区 |
| `v` | 将对话写入临时文件并在 `$VISUAL` 或 `$EDITOR` 中打开它 |
| `q`、`Ctrl+C`、`Esc` | 退出转录视图 |

### 语音输入

| 快捷键 | 描述 |
|--------|------|
| 按住或点击 `Space` | 语音听写。需要启用语音听写 |

## Vim 编辑器模式

通过 `/config` → 编辑器模式启用 vim 风格编辑。

### 模式切换

| 命令 | 操作 | 来自模式 |
|------|------|---------|
| `Esc` | 进入 NORMAL 模式 | INSERT、VISUAL |
| `i` | 在光标前插入 | NORMAL |
| `I` | 在行首插入 | NORMAL |
| `a` | 在光标后插入 | NORMAL |
| `A` | 在行尾插入 | NORMAL |
| `o` | 在下方打开行 | NORMAL |
| `O` | 在上方打开行 | NORMAL |
| `v` | 开始字符级可视选择 | NORMAL |
| `V` | 开始行级可视选择 | NORMAL |

### NORMAL 模式导航

| 命令 | 操作 |
|------|------|
| `h`/`j`/`k`/`l` | 向左/向下/向上/向右移动 |
| `Space` | 向右移动 |
| `w` | 下一个单词 |
| `e` | 单词末尾 |
| `b` | 上一个单词 |
| `0` | 行首 |
| `$` | 行尾 |
| `^` | 第一个非空白字符 |
| `gg` | 输入开始 |
| `G` | 输入结束 |
| `f{char}` | 跳转到下一个字符出现处 |
| `F{char}` | 跳转到上一个字符出现处 |
| `t{char}` | 跳转到下一个字符出现处之前 |
| `T{char}` | 跳转到上一个字符出现处之后 |
| `;` | 重复最后一个 f/F/t/T 动作 |
| `,` | 反向重复最后一个 f/F/t/T 动作 |

### NORMAL 模式编辑

| 命令 | 操作 |
|------|------|
| `x` | 删除字符 |
| `dd` | 删除行 |
| `D` | 删除到行尾 |
| `dw`/`de`/`db` | 删除单词/到末尾/向后 |
| `cc` | 更改行 |
| `C` | 更改到行尾 |
| `cw`/`ce`/`cb` | 更改单词/到末尾/向后 |
| `yy`/`Y` | 复制行 |
| `yw`/`ye`/`yb` | 复制单词/到末尾/向后 |
| `p` | 在光标后粘贴 |
| `P` | 在光标前粘贴 |
| `>>` | 缩进行 |
| `<<` | 取消缩进行 |
| `J` | 连接行 |
| `u` | 撤销 |
| `.` | 重复最后一个更改 |

### 文本对象（与 `d`、`c`、`y` 等运算符一起工作）

| 命令 | 操作 |
|------|------|
| `iw`/`aw` | 内部/周围单词 |
| `iW`/`aW` | 内部/周围 WORD（空白分隔） |
| `i"`/`a"` | 内部/周围双引号 |
| `i'`/`a'` | 内部/周围单引号 |
| `i(`/`a(` | 内部/周围括号 |
| `i[`/`a[` | 内部/周围方括号 |
| `i{`/`a{` | 内部/周围大括号 |

### 可视模式

按 `v` 进行字符级选择或按 `V` 进行行级选择。

| 命令 | 操作 |
|------|------|
| `d`/`x` | 删除选择 |
| `y` | 复制选择 |
| `c`/`s` | 更改选择 |
| `p` | 用寄存器内容替换选择 |
| `r{char}` | 将每个选定的字符替换为 `{char}` |
| `~`/`u`/`U` | 切换、小写或大写选择 |
| `>`/`<` | 缩进或取消缩进选定的行 |
| `J` | 连接选定的行 |
| `o` | 交换光标和锚点 |
| `v`/`V` | 在字符级和行级之间切换，或退出 |

> 不支持使用 `Ctrl+V` 的块级可视模式。

## 命令历史技巧

- 输入历史按工作目录存储
- 当您运行 `/clear` 以启动新会话时，输入历史会重置。上一个会话的对话被保留并可以恢复
- 使用向上/向下箭头导航命令历史
- **注意**：历史扩展（`!`）默认禁用

### 使用 Ctrl+R 反向搜索

1. **开始搜索**：按 `Ctrl+R` 激活反向历史搜索
2. **键入查询**：输入文本以在以前的命令中搜索。搜索词在匹配结果中突出显示
3. **导航匹配**：再次按 `Ctrl+R` 以循环浏览较旧的匹配
4. **更改范围**：搜索默认为来自所有项目的提示。按 `Ctrl+S` 在此会话、此项目和所有项目之间循环范围
5. **接受匹配**：
   - 按 `Tab` 或 `Esc` 接受当前匹配并继续编辑
   - 按 `Enter` 接受并立即执行命令
6. **取消搜索**：
   - 按 `Ctrl+C` 取消并恢复原始输入
   - 在空搜索上按 `Backspace` 以取消

## 后台 Bash 命令技巧

Claude Code 支持在后台运行 bash 命令，允许您在长时间运行的进程执行时继续工作。

### 如何在后台运行

- 提示 Claude Code 在后台运行命令
- 按 `Ctrl+B` 将常规 Bash 工具调用移到后台（Tmux 用户必须按 `Ctrl+B` 两次）

### 主要功能

- 输出被写入文件，Claude 可以使用 Read 工具检索它
- 后台任务具有唯一的 ID 用于跟踪和输出检索
- 当 Claude Code 退出时，后台任务会自动清理
- 如果输出超过 5GB，后台任务会自动终止

### 常见的后台命令

- 构建工具（webpack、vite、make）
- 包管理器（npm、yarn、pnpm）
- 测试运行器（jest、pytest）
- 开发服务器
- 长时间运行的进程（docker、terraform）

### 禁用后台任务

要禁用所有后台任务功能，请将 `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS` 环境变量设置为 `1`。

## `!` Bash 模式技巧

通过在输入前加上 `!` 来直接运行 bash 命令，无需通过 Claude：

```
! npm test
! git status
! ls -la
```

### Bash 模式特性

- 将命令及其输出添加到对话上下文
- 显示实时进度和输出
- 支持相同的 `Ctrl+B` 后台运行长时间运行的命令
- 不需要 Claude 解释或批准命令
- 支持基于历史的自动完成：键入部分命令并按 **Tab** 以从当前项目中的上一个 `!` 命令完成
- 使用 `Escape`、`Backspace` 或在空提示上使用 `Ctrl+U` 退出
- 将以 `!` 开头的文本粘贴到空提示中会自动进入 bash 模式

## 提示建议技巧

当您首次打开会话时，灰显的示例命令会出现在提示输入中以帮助您入门。

### 提示建议行为

- Claude Code 从您的项目的 git 历史中选择此命令
- Claude 响应后，建议会根据您的对话历史继续出现
- 按 **Tab** 或 **Right arrow** 接受建议，或按 **Enter** 接受并提交
- 开始输入以关闭它

### 禁用提示建议

```bash
export CLAUDE_CODE_ENABLE_PROMPT_SUGGESTION=false
```

或在 `/config` 中切换设置。

## `/btw` 侧面问题技巧

使用 `/btw` 快速提问您当前的工作，而不添加到对话历史。

### 特性

- **Claude 工作时可用**：即使 Claude 正在处理响应时，您也可以运行 `/btw`
- **无工具访问**：侧面问题仅从已在上下文中的内容回答，无法读取文件、运行命令或搜索
- **单一响应**：没有后续轮次
- **低成本**：侧面问题重用父对话的提示缓存

### 使用场景

- 快速答案但不想混乱主要上下文
- 询问 Claude 已经读过的代码或之前做出的决定
- 不使 Claude 偏离长时间运行的任务

> `/btw` 是 subagent 的反面：它看到您的完整对话但没有工具，而 subagent 具有完整工具但从空上下文开始。

## 任务列表技巧

在处理复杂的多步骤工作时，Claude 会创建任务列表来跟踪进度。

### 任务列表操作

- 按 `Ctrl+T` 切换任务列表视图。显示一次最多 5 个任务
- 要查看所有任务或清除它们，直接询问 Claude："show me all tasks" 或 "clear all tasks"
- 任务在上下文压缩中持续存在

### 跨会话共享任务列表

设置 `CLAUDE_CODE_TASK_LIST_ID` 以使用 `~/.claude/tasks/` 中的命名目录：

```bash
CLAUDE_CODE_TASK_LIST_ID=my-project claude
```

## 会话回顾技巧

当您从离开后返回终端时，Claude Code 会显示到目前为止会话中发生的情况的单行回顾。

### 触发条件

- 至少自上次完成的轮次以来已经过了三分钟且终端未聚焦
- 仅在会话至少有三个轮次后出现
- 永远不会连续出现两次

### 操作

- 运行 `/recap` 以按需生成摘要
- 要关闭自动回顾，打开 `/config` 并禁用**会话回顾**
- 回顾在非交互模式下始终被跳过

## PR 审查状态技巧

在处理具有开放拉取请求的分支时，Claude Code 在页脚中显示可点击的 PR 链接。

### 状态颜色含义

- **绿色**：已批准
- **黄色**：待审查
- **红色**：请求更改
- **灰色**：草稿
- **紫色**：已合并

### 操作

- `Cmd+click`（Mac）或 `Ctrl+click`（Windows/Linux）链接以在浏览器中打开拉取请求
- 状态每 60 秒自动更新一次
