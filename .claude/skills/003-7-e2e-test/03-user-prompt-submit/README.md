# 补充上下文目录

本目录存放 `.md` 文件，每次调用对应技能时，`03UserPromptSubmit.sh` 会自动加载目录内所有 MD 文件作为额外上下文注入。

## 用途

- **学习进化**：技能在实际使用中发现问题或偏差时，将修正内容写入此目录的 MD 文件
- **项目定制**：针对特定项目的补充规则、约定或示例
- **经验积累**：记录使用过程中发现的边界情况、最佳实践

## 命名规范

文件按字母序加载，建议用前缀编号控制顺序：

```
01-修正-边界检查补充.md
02-项目定制-响应格式.md
03-经验-并发场景补充.md
```

## 注意

- 文件内容会直接注入为 `additionalContext`，请保持简洁
- 修改后立即生效，无需重启
- 空目录不加载任何内容
