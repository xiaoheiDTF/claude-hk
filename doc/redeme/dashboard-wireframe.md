# Claude Tap Plus Dashboard 线框图设计

> 本文档定义可视化仪表板的页面布局、数据源和交互设计。

---

## 1. 整体布局框架

```
┌─────────────────────────────────────────────────────────────────────────────┐

├──────┬──────────────────────────────────────────────────────────────────────┤
```

**布局规则**：
- 左侧导航栏固定宽度 ~60px（图标+文字），深色背景
- 顶部栏显示当前页面标题 + 全局操作（设置、主题切换）
- 内容区域采用 CSS Grid 布局，响应式自适应
- 数字卡片行：5 列等宽
- 图表行：2 列（左 60% / 右 40%）或 1 列全宽
- 表格行：1 列全宽

## 2. 侧边栏导航

```
┌──────────────┐
│              │
│  🏠 概览     │  ← 默认选中，4 个数字卡片 + 趋势图 + 会话列表 + Issue 分布
│              │
│  🪙 Token    │  ← Token 用量详情：趋势/对比/排行/饼图
│              │
│  📋 Issue    │  ← 看板视图 + 状态流转时间线 + 领取者分布
│              │
│  ⏱️ 性能     │  ← 响应时间分布/趋势 + 慢请求排行
│              │
│  🔧 Hook     │  ← 事件频率 + 工具调用排行 + 热力图
│              │
│  ──────────  │
│              │
│  🌐 机器: 1  │  ← 点击展开机器列表
│  📁 项目: 1  │  ← 点击展开项目列表
│              │
│  ──────────  │
│              │
│  🔄 刷新     │  ← 手动刷新数据
│  ⚙️ 设置     │  ← 数据库路径、刷新间隔等配置
│              │
└──────────────┘
```

**交互**：
- 点击导航项切换右侧内容面板
- 当前选中项高亮显示
- 底部「机器」「项目」可点击展开详情弹窗
- 「刷新」按钮触发数据重新加载，带 loading 状态

| 组件 | 数据来源 | API 端点 |

| 数字卡片（5个） | `sessions` + `issue_claims` + trace JSONL | `GET /api/dashboard/overview` |

### 数据源

| 组件 | 数据来源 | 说明 |
|------|---------|------|
| 4 个数字卡片 | trace JSONL 聚合 | 全部文件的 `body.usage` 字段累加 |
| 会话对比堆叠柱状图 | trace JSONL 按 session 聚合 | 每个会话文件单独统计 |
| Token 趋势折线图 | trace JSONL 逐条读取 | x 轴 = 调用序号，y 轴 = tokens |
| 输入输出饼图 | trace JSONL 汇总 | 两个值的占比 |
| 排行表 | trace JSONL 按 session 排序 | 按总 Token 降序 |

### 数据提取逻辑

```python
# 每条 trace JSONL 记录结构
{
  "duration_ms": 12219,
  "response": {
    "body": {
      "model": "glm-5.1",
      "usage": {
        "input_tokens": 102605,
        "output_tokens": 104,
        "cache_read_input_tokens": 25984,
        "cache_creation_input_tokens": 0
      }
    }
  }
}
```

### 交互

- 顶部时间筛选器：`[今天|本周|全部]` 过滤 trace 文件
- 堆叠柱状图切换：`[柱状|堆叠]` 切换普通柱状图和堆叠柱状图
- 排行表行可点击跳转到该会话的详情
- 数字卡片的 `▲ 节省 $X.XX` 可配置 Token 单价计算费用

### 日志格式解析

```bash
# 日志行格式
[2026-05-31 00:38:34] [INFO] [PreToolUse] tool=Bash
[2026-05-31 00:38:35] [INFO] [PostToolUse] tool=Read
[2026-05-31 00:38:36] [INFO] [SessionStart] os=windows
```

提取规则：
- 事件类型：`\[INFO\] \[(\w+)\]`
- 工具名：`tool=(\w+)`（仅 PreToolUse 事件）
- 时间戳：`\[(\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2})\]`

### 交互

- 事件类型排行柱子可点击筛选只看该事件
- 热力图格子可点击查看该小时的详细事件列表
- 工具调用排行横向柱状图，hover 显示百分比

## 9. 技术选型建议

| 层级 | 技术 | 理由 |
|------|------|------|
| 后端 | Go（现有后端扩展） | 零额外依赖，端口复用 8080 |
| 前端框架 | 纯 HTML + Vanilla JS | 轻量，无需 Node.js 构建 |
| 图表库 | ECharts（CDN 引入） | 功能强大，中文文档完善 |
| 样式 | CSS Grid + CSS Variables | 简洁，支持暗色主题 |
| 数据刷新 | 轮询 30s 或手动刷新 | 简单可靠 |

### 文件结构

```
claude_tap_plus/
└── internal/
    └── backend/
        └── api/
            ├── dashboard_handler.go    # 新增：仪表板 API 处理器
            ├── dashboard_data.go       # 新增：数据聚合逻辑
            └── dashboard_assets.go     # 新增：静态资源 embed
```

前端静态文件 embed 到 Go 二进制中，无需额外文件部署。
