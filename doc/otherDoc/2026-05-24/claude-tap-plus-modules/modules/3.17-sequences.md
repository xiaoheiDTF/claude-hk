# 3.17 时序图合集

> 来源于 09-module-functional-design.md §6-12

## 6. 总体时序图

```mermaid
sequenceDiagram
    participant User as 用户
    participant CLI as CLI Router
    participant Project as Project Resolver
    participant Storage as Storage Manager
    participant Module as 目标模块

    User->>CLI: 执行 claude-tap-plus 命令
    CLI->>Project: 识别 project/cwd/git/branch/slug
    Project-->>CLI: 返回项目身份
    CLI->>Storage: 获取固定存储路径
    Storage-->>CLI: 返回 db/trace/session/log 路径
    CLI->>CLI: 解析命令模式
    CLI->>Module: 调用目标功能
    Module-->>CLI: 返回结果
    CLI-->>User: 输出结果
```

## 7. Proxy Trace 时序图

```mermaid
sequenceDiagram
    participant User as 用户
    participant CLI as CLI Router
    participant Proxy as Proxy Trace
    participant Claude as Claude Code
    participant API as 上游 API
    participant SSE as SSE Reassembler
    participant Usage as Usage Normalizer
    participant Trace as Trace Writer

    User->>CLI: claude-tap-plus claude
    CLI->>Proxy: 启动本地代理
    CLI->>Claude: 注入代理地址并启动
    Claude->>Proxy: API 请求
    Proxy->>API: 转发请求
    API-->>Proxy: 返回响应/SSE
    Proxy->>SSE: 如为 streaming 则重组
    Proxy->>Usage: 归一化 token 用量
    Proxy->>Trace: 写入 JSONL trace
    Proxy-->>Claude: 返回响应
    Claude-->>User: 输出交互内容
    CLI-->>User: 退出时输出 usage summary
```

## 8. Session 时序图

```mermaid
sequenceDiagram
    participant User as 用户
    participant CLI as CLI Router
    participant Session as Session Module
    participant ClaudeDir as Claude 原始目录
    participant Storage as 固定存储
    participant DB as Local DB

    alt session-collect
        User->>CLI: session-collect
        CLI->>Session: 扫描 session
        Session->>ClaudeDir: 只读扫描
        Session->>DB: 写入索引
        Session-->>CLI: 返回统计
    else session-import
        User->>CLI: session-import 外部路径
        CLI->>Session: 导入外部数据
        Session->>Storage: 复制到固定目录
        Session->>DB: 写入 source=import
        Session-->>CLI: 返回导入结果
    else session-find
        User->>CLI: session-find 条件
        CLI->>Session: 查询
        Session->>DB: 读取索引
        Session-->>CLI: 返回结果
    else session-push/pull/status
        User->>CLI: session-push/pull/status
        CLI->>Session: 执行快照功能
        Session->>ClaudeDir: 读取或写入原始 session
        Session->>Storage: 读写本地快照
        Session-->>CLI: 返回结果
    end
    CLI-->>User: 展示结果
```

## 9. Issue 工作流时序图

```mermaid
sequenceDiagram
    participant User as 用户/Agent
    participant Skill as Skill
    participant Guard as Hooks Guard
    participant Issue as Issue Mirror
    participant DB as Local DB
    participant GitHub as GitHub
    participant Log as Activity Log

    User->>Skill: claim/fix/pr/test/review
    Skill->>Issue: 查询 issue 状态
    Issue->>DB: 读取本地镜像
    DB-->>Issue: 返回 issue/依赖/PR
    Issue-->>Skill: 返回状态
    Skill->>Guard: 请求操作前检查
    Guard->>Issue: 查询规则所需状态
    Issue-->>Guard: 返回状态
    alt block
        Guard->>Log: 记录阻断
        Guard-->>Skill: 返回阻断原因
    else allow/warn
        Guard->>Log: 记录通过或提醒
        Guard-->>Skill: 返回决策
        Skill->>GitHub: 用户显式动作
        Skill->>Issue: 写入活动并触发同步
    end
```

## 10. Sandbox 与 Tool Adapter 时序图

```mermaid
sequenceDiagram
    participant User as 用户
    participant CLI as CLI Router
    participant Project as Project Resolver
    participant Sandbox as Sandbox Manager
    participant Git as Git Worktree
    participant Tool as Tool Adapter
    participant App as 目标工具
    participant Meta as Metadata

    User->>CLI: --sandbox feature-a --tool claude resume session_id
    CLI->>Project: 识别当前项目
    Project-->>CLI: 返回 project identity
    CLI->>Sandbox: 查找 feature-a sandbox
    Sandbox->>Git: 检查 branch/worktree
    alt sandbox 不存在
        Git-->>Sandbox: 创建 worktree
    else sandbox 已存在
        Git-->>Sandbox: 返回 worktree
    end
    Sandbox->>Meta: 更新 sandbox 元数据
    CLI->>Tool: 选择 claude adapter
    Tool->>App: 在 worktree 内执行 claude resume session_id
    Tool->>Meta: 记录工具启动
    App-->>User: 进入目标工作环境
```

## 11. Scheduler 时序图

```mermaid
sequenceDiagram
    participant Timer as 定时器/用户
    participant Scheduler as Scheduler
    participant Issue as Issue Mirror
    participant DB as Local DB
    participant GitHub as GitHub
    participant Log as Activity Log

    Timer->>Scheduler: 触发任务
    Scheduler->>Issue: 查询 issue 状态
    Issue->>DB: 读取 issues/activity/dependencies
    DB-->>Issue: 返回状态
    Issue-->>Scheduler: 返回候选 issue
    Scheduler->>Scheduler: 生成治理计划
    alt dry-run
        Scheduler->>Log: 记录 preview
        Scheduler-->>Timer: 输出计划
    else execute
        Scheduler->>Log: 记录计划动作
        Scheduler->>GitHub: 执行 label/comment/assign 更新
        GitHub-->>Scheduler: 返回结果
        Scheduler->>Issue: 同步最新状态
        Scheduler-->>Timer: 输出执行报告
    end
```

## 12. 同步时序图

```mermaid
sequenceDiagram
    participant User as 用户
    participant CLI as CLI Router
    participant Sync as Sync Module
    participant Storage as 固定存储
    participant Git as Git
    participant Remote as 远端/外部存储
    participant Main as 主项目目录

    User->>CLI: sync/import/export/apply
    CLI->>Sync: 请求同步动作
    alt metadata sync
        Sync->>Storage: 同步 metadata/session/trace
        Sync->>Remote: 上传或下载
    else git fetch
        Sync->>Git: fetch 远端信息
    else sandbox pull/push
        Sync->>Git: 用户显式 pull/push sandbox branch
    else apply to local
        Sync->>Git: 生成 sandbox diff
        Sync-->>User: 展示变更并要求确认
        User-->>Sync: 确认
        Sync->>Main: 应用到主项目目录
    end
    Sync-->>CLI: 返回同步报告
    CLI-->>User: 展示结果
```
