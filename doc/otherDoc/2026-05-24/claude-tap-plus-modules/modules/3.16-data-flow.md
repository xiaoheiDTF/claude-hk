# 3.16 数据流转

> 来源于 09-module-functional-design.md §5

## 5.1 Proxy Trace 数据流

```text
Claude Code API 请求
  -> Local Proxy
  -> Upstream API
  -> Local Proxy
  -> SSE Reassembler
  -> Usage Normalizer
  -> Trace Writer
  -> 固定存储 traces/
  -> Session/Usage 查询
```

## 5.2 Session 数据流

**Collect（只读索引）：**

```text
Claude 原始 session
  -> session-collect 只读扫描
  -> Session Index
  -> Local DB
  -> session-find 查询
```

**Import（外部导入）：**

```text
外部 trace/session
  -> session-import
  -> 固定存储 imports/traces/sessions
  -> Session Index
  -> Local DB
```

**Snapshot（快照同步）：**

```text
Claude 原始 session
  -> session-push
  -> 本地快照 sessions/
  -> session-status
  -> session-pull
  -> Claude 原始目录
```

## 5.3 Issue 数据流

```text
GitHub Issues
  -> Issue Mirror sync/webhook
  -> Local DB
  -> /issues /board /ready
  -> Hooks Guard / Skills / Scheduler
  -> 用户显式动作或 scheduler 动作
  -> GitHub
  -> Issue Mirror 再同步
```

## 5.4 Sandbox 数据流

```text
用户命令 --sandbox branch
  -> Project Resolver
  -> Sandbox Manager
  -> Git Worktree
  -> Tool Adapter
  -> Claude/Cursor/IDEA/Trae
  -> sandbox worktree 文件变化
  -> sandbox diff/status
  -> 用户显式 apply/sync
  -> 主项目或远端
```
