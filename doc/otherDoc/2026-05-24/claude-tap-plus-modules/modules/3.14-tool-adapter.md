# 3.14 Tool Adapter 模块

> 来源于 09-module-functional-design.md §3.14、07-sandbox.md

## 作用

1. 根据 `--tool` 启动目标工具。
2. 把工具启动目录切换到 sandbox worktree。
3. 透传工具后续命令。

## 功能

### 功能 1：Tool Adapter 透传

根据 `--tool` 启动对应工具。

1. `--tool claude` 在 worktree 内启动 Claude Code。
2. `--tool cursor` 打开 worktree。
3. `--tool idea` 打开 worktree。
4. `--tool trae` 打开 worktree。
5. `--tool cmd` 打开位于 worktree 的终端。
6. tool 后续参数原样传给对应工具。

## 支持工具

| Tool | 行为 |
|------|------|
| claude | 在 worktree 内启动 Claude Code，可透传 resume/new/reload |
| cursor | 打开 worktree |
| idea | 打开 worktree |
| trae | 打开 worktree |
| cmd | 打开位于 worktree 的终端 |
