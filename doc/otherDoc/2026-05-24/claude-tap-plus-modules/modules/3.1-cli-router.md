# 3.1 CLI Router 模块设计

> 来源于 09-module-functional-design.md §3.1
> 2026-05-24 设计：MVP 只做当前需求的命令集。

## 命令总览与模块归属

CLI Router 是唯一用户入口，所有命令按功能分发到对应模块处理。按模块归属如下：

```text
claude-tap-plus <command>
│
├── Proxy 模块 (3.4) ─────────── API 代理与 trace 记录
│   ├── claude [args...]           → 启动 Claude Code 代理
│   ├── kimi [args...]             → 启动 Kimi CLI 代理
│   └── (无子命令，默认)           → 自动检测并启动代理
│
├── Session 模块 (3.8) ────────── Session 索引与快照
│   ├── session-collect [flags]    → 扫描本机 session/trace 建索引
│   ├── session-find [flags]       → 按条件查询 SQLite 索引
│   ├── session-import [flags]     → 从外部目录导入 traces
│   ├── session-push [flags]       → session 快照收集（已有）
│   ├── session-pull [flags]       → session 恢复（已有）
│   └── session-status [flags]     → session 存储状态（已有）
│
├── Issue Mirror 模块 (3.9) ──── GitHub Issue 本地镜像
│   └── serve                       → 启动本地 HTTP 服务
│        └── 内含 Scheduler (3.12) → 定时治理 stale/blocked issue
│
├── Tool Adapter 模块 (3.14) ─── Claude CLI 适配
│   ├── tool claude [options] [prompt]    → 启动 Claude Code（叠加 trace）
│   ├── tool claude mcp <sub> [opts]      → Claude MCP 管理（add/list/get/remove/serve）
│   ├── tool claude auth <sub> [opts]     → Claude 认证（login/status/logout）
│   ├── tool claude plugin <sub> [opts]   → Claude 插件（install/list/enable/disable/...）
│   ├── tool claude project <sub> [opts]  → Claude 项目（purge）
│   ├── tool claude agents [opts]         → Claude 后台 agent 管理
│   ├── tool claude doctor                → Claude 健康检查
│   ├── tool claude install [target]      → Claude 安装
│   ├── tool claude update                → Claude 更新
│   ├── tool claude setup-token           → Claude token 设置
│   ├── tool claude ultrareview [opts]    → Claude 云端 review（后续）
│   ├── tool claude auto-mode             → Claude auto mode（后续）
│   ├── tool list                         → 列出可用工具
│   └── tool which <tool>                 → 查找工具路径
│
├── Sync 模块 (3.15) ──────────── 跨机器同步
│   └── sync                        → 同步 metadata/trace/session
│
└── 通用 ────────────────────────── 不归属特定模块
    ├── help / --help / -h          → 打印帮助
    └── version / --version         → 显示版本
```

### 模块命令统计

| 模块 | 命令数 | MVP 状态 |
|------|--------|----------|
| Proxy (3.4) | 3（claude / kimi / 默认） | **MVP** |
| Session (3.8) | 6（collect/find/import/push/pull/status） | **MVP**（collect/find/import 新增） |
| Issue Mirror (3.9) | 1（serve） | 后续 |
| Scheduler (3.12) | 内嵌于 serve | 后续 |
| Tool Adapter (3.14) | 16（claude 12 子命令 + list + which + config + kill） | **MVP**（claude 全命令适配） |
| Sync (3.15) | 1（sync） | 后续 |
| 通用 | 2（help / version） | **MVP** |
| **合计** | **29** | MVP: 27 |

### 命令分层

```text
第一层：子命令（必须第一个参数）
  claude | kimi | session-* | serve | sync | help | version

第二层：子命令参数
  --tap-*    → Proxy 模块消费（--tap-target / --tap-port / --tap-verbose）
  --tool     → Tool Adapter 消费
  --flag     → 各子命令自己的参数

第三层：透传参数
  --         → 后续参数原样传给目标工具（claude / kimi）
```

## 路由分发逻辑

```text
claude-tap-plus [args]
  │
  │ ── Tool Adapter 模块 (3.14) ──
  ├── args[0] == "tool"               → runTool(args[1:])
  │   ├── args[1] == "claude"         → runToolClaude(args[2:])
  │   │   ├── args[2] == "mcp"        → claude mcp <args[3:]>
  │   │   ├── args[2] == "auth"       → claude auth <args[3:]>
  │   │   ├── args[2] == "plugin"     → claude plugin <args[3:]>
  │   │   ├── args[2] == "project"    → claude project <args[3:]>
  │   │   ├── args[2] == "agents"     → claude agents <args[3:]>
  │   │   ├── args[2] == "doctor"     → claude doctor
  │   │   ├── args[2] == "install"    → claude install <args[3:]>
  │   │   ├── args[2] == "update"     → claude update
  │   │   ├── args[2] == "setup-token"→ claude setup-token
  │   │   ├── args[2] == "ultrareview"→ claude ultrareview <args[3:]>
  │   │   ├── args[2] == "auto-mode"  → claude auto-mode
  │   │   └── 其他                    → claude <args[2:]> (交互式 + options)
  │   ├── args[1] == "list"           → listAvailableTools()
  │   └── args[1] == "which"          → whichTool(args[2])
  │
  │ ── Proxy 模块 (3.4) ──
  ├── args[0] == "claude"             → runProxy(ClaudeClient, args[1:])
  ├── args[0] == "kimi"               → runProxy(KimiClient, args[1:])
  │
  │ ── Session 模块 (3.8) ──
  ├── args[0] == "session-collect"    → runSessionCollect(args[1:])
  ├── args[0] == "session-find"       → runSessionFind(args[1:])
  ├── args[0] == "session-import"     → runSessionImport(args[1:])
  ├── args[0] == "session-push"       → runSessionPush(args[1:])
  ├── args[0] == "session-pull"       → runSessionPull(args[1:])
  ├── args[0] == "session-status"     → runSessionStatus(args[1:])
  │
  │ ── 通用 ──
  ├── args[0] == "help" / --help      → printUsage()
  ├── args[0] == "version" / --version→ printVersion()
  │
  │ ── 后续模块占位 ──
  ├── args[0] == "serve"              → runServe(args[1:])           // Issue Mirror (3.9)
  ├── args[0] == "sync"               → runSync(args[1:])            // Sync (3.15)
  │
  └── 其他                            → 自动检测并启动代理（兼容旧用法）  // Proxy (3.4)
        ├── 检测到 --claude           → runProxy(ClaudeClient, args)
        ├── 检测到 --kimi             → runProxy(KimiClient, args)
        └── 默认                      → runProxy(ClaudeClient, args)
```

### 分发规则

1. `args[0]` 匹配已知子命令 → 路由到对应模块处理函数。
2. `args[0]` 不匹配任何子命令 → 走默认代理模式（向后兼容当前行为）。
3. 后续模块（serve/sync）预留路由，MVP 阶段输出 "not yet implemented"。
4. 每个处理函数只消费自己的参数，剩余部分按规则透传或报错。

#### A.3 `tool claude`（交互式会话）

映射 `claude` 的全部启动选项。claude-tap-plus 在此基础上叠加 trace 代理。

```bash
# ── 基本启动 ──

# 启动 Claude Code 交互式会话
claude-tap-plus tool claude

# 直接透传（等同直接调用 claude）
claude-tap-plus tool claude

# ── 会话恢复 ──

# 继续最近一次会话 (-c / --continue)
claude-tap-plus tool claude --continue

# 恢复指定会话 (-r / --resume)
claude-tap-plus tool claude --resume

# 恢复时创建新 session ID（不覆盖原始会话）
claude-tap-plus tool claude --resume --fork-session

# 按 PR 恢复会话
claude-tap-plus tool claude --from-pr 42

# 使用指定 session ID
claude-tap-plus tool claude --session-id <uuid>

# ── 非交互式模式 ──

# -p / --print：输出后退出（管道友好）
claude-tap-plus tool claude --print "解释这个函数"
claude-tap-plus tool claude -p "运行测试并报告结果"

# JSON 输出
claude-tap-plus tool claude -p "列出所有 TODO" --output-format json

# 流式 JSON 输出
claude-tap-plus tool claude -p "重构 auth" --output-format stream-json

# ── 模型与权限 ──

# 指定模型
claude-tap-plus tool claude --model sonnet
claude-tap-plus tool claude --model opus

# effort 级别
claude-tap-plus tool claude --effort high

# 权限模式
claude-tap-plus tool claude --permission-mode plan
claude-tap-plus tool claude --permission-mode bypassPermissions

# 预算限制（仅 --print）
claude-tap-plus tool claude -p "快速检查" --max-budget-usd 0.5

# ── 工具控制 ──

# 允许/禁用特定工具
claude-tap-plus tool claude --allowedTools "Bash(git *) Edit Read"
claude-tap-plus tool claude --disallowedTools "Bash(rm *)"

# 指定可用工具集
claude-tap-plus tool claude --tools "Bash,Edit,Read"

# ── Prompt 控制 ──

# 直接传入 prompt
claude-tap-plus tool claude "修复 OAuth token 刷新 bug"

# 追加系统 prompt
claude-tap-plus tool claude --append-system-prompt "Always write tests"

# 自定义系统 prompt（替换默认）
claude-tap-plus tool claude --system-prompt "You are a security auditor"

# ── MCP 配置 ──

# 加载 MCP 配置文件
claude-tap-plus tool claude --mcp-config ./mcp-servers.json

# 严格 MCP 模式（只使用指定配置）
claude-tap-plus tool claude --mcp-config ./mcp.json --strict-mcp-config

# ── 插件 ──

# 加载插件目录
claude-tap-plus tool claude --plugin-dir ./my-plugin

# 从 URL 加载插件
claude-tap-plus tool claude --plugin-url https://example.com/plugin.zip

# ── Agent 配置 ──

# 指定 agent
claude-tap-plus tool claude --agent reviewer

# 自定义 agent（JSON）
claude-tap-plus tool claude --agents '{"reviewer":{"description":"Reviews code","prompt":"You are a code reviewer"}}'

# ── Worktree 集成 ──

# 创建临时 worktree（Claude 原生 worktree）
claude-tap-plus tool claude --worktree
claude-tap-plus tool claude -w fix-auth-temp

# ── 其他选项 ──

# 设置会话名称
claude-tap-plus tool claude --name "auth-fix-session"

# 详细输出
claude-tap-plus tool claude --verbose

# 调试模式
claude-tap-plus tool claude --debug
claude-tap-plus tool claude --debug "api,hooks"

# 调试日志写入文件
claude-tap-plus tool claude --debug-file ./debug.log

# 添加额外可访问目录
claude-tap-plus tool claude --add-dir ../shared-lib

# IDE 集成
claude-tap-plus tool claude --ide

# Chrome 集成
claude-tap-plus tool claude --chrome

# 禁用 slash commands
claude-tap-plus tool claude --disable-slash-commands

# Remote Control 模式
claude-tap-plus tool claude --remote-control my-session

# JSON Schema 约束输出（仅 --print）
claude-tap-plus tool claude -p "列出文件" --json-schema '{"type":"object","properties":{"files":{"type":"array"}}}'

# 设置文件来源
claude-tap-plus tool claude --file file_abc:doc.txt

# 设置来源
claude-tap-plus tool claude --setting-sources user,project
```

#### A.4 `tool claude mcp`（MCP 服务器管理）

映射 `claude mcp` 全部子命令。

```bash
# ── 添加 MCP 服务器 ──

# 添加 HTTP 类型服务器
claude-tap-plus tool claude mcp add --transport http sentry https://mcp.sentry.dev/mcp

# 添加带 header 的 HTTP 服务器
claude-tap-plus tool claude mcp add --transport http corridor https://app.corridor.dev/api/mcp \
  --header "Authorization: Bearer xxx"

# 添加 stdio 类型服务器（带环境变量）
claude-tap-plus tool claude mcp add -e API_KEY=xxx my-server -- npx my-mcp-server

# 添加 stdio 类型服务器（带子进程参数）
claude-tap-plus tool claude mcp add my-server -- my-command --some-flag arg1

# 用 JSON 添加
claude-tap-plus tool claude mcp add-json my-server '{"type":"stdio","command":"npx","args":["my-server"]}'

# 从 Claude Desktop 导入
claude-tap-plus tool claude mcp add-from-claude-desktop

# ── 查询 ──

# 列出所有 MCP 服务器
claude-tap-plus tool claude mcp list

# 查看指定服务器详情
claude-tap-plus tool claude mcp get sentry

# ── 删除 ──

# 删除 MCP 服务器
claude-tap-plus tool claude mcp remove sentry

# 重置项目级 MCP 选择
claude-tap-plus tool claude mcp reset-project-choices

# ── MCP 服务模式 ──

# 启动 Claude Code 自身作为 MCP Server
claude-tap-plus tool claude mcp serve
claude-tap-plus tool claude mcp serve --debug
claude-tap-plus tool claude mcp serve --verbose
```

#### A.12 参数分层与路由规则

```text
claude-tap-plus tool claude [subcmd] [args...]

                    │       │        └── Claude 原生参数，原样透传
                    │       └── Claude 子命令：mcp/auth/plugin/project/agents/...
                    └── tap-plus 专属参数（--tap-*）
```

**路由规则：**

1. `tool claude` 后第一个 token 匹配已知 Claude 子命令（`mcp`/`auth`/`plugin`/`project`/`agents`/`doctor`/`install`/`update`/`setup-token`/`ultrareview`/`auto-mode`）→ 提取子命令，剩余参数透传。
2. 第一个 token 不匹配任何 Claude 子命令 → 视为 `claude` 交互式启动参数。
3. `--tap-*` 等 tap-plus 专属参数在路由层提取，不传给 Claude。
4. 所有 Claude 原生参数原样透传，不做校验或转换。

**示例流程：**

```text
输入: claude-tap-plus tool claude -p "hello" --model sonnet

解析:
  tap-plus 提取:   (无)
  Claude 透传:   -p "hello" --model sonnet
  执行: claude -p "hello" --model sonnet
```

```text
输入: claude-tap-plus tool claude mcp add --transport http sentry https://mcp.sentry.dev/mcp

解析:
  Claude 子命令: mcp add
  Claude 透传:   --transport http sentry https://mcp.sentry.dev/mcp
  执行: claude mcp add --transport http sentry https://mcp.sentry.dev/mcp
```

```text
输入: claude-tap-plus tool claude auth status

解析:
  Claude 子命令: auth status

  执行: claude auth status
```

### B. Session 模块命令（Session 3.8）

> 核心职责：session 索引扫描、跨机器导入、多维查询、快照同步。

#### B.1 命令语法

```text
claude-tap-plus session-<action> [options]
```

#### B.2 子命令一览

| 命令 | 说明 | MVP |
|------|------|-----|
| `session-collect` | 扫描本机 session/trace 建索引 | ✓ |
| `session-find` | 按条件查询 SQLite 索引 | ✓ |
| `session-import` | 从外部目录/文件导入 trace | ✓ |
| `session-push` | 收集 session 到本地副本（快照） | ✓ |
| `session-pull` | 从本地副本恢复 session | ✓ |
| `session-status` | 查看 session 存储状态 | ✓ |
| `session-show` | 显示单个 session 完整信息 | 后续 |
| `session-export` | 导出 session/trace 到外部目录 | 后续 |

#### B.3 `session-collect`

扫描本机 Claude Code session 文件和 trace 文件，解析后写入本地 SQLite 索引。

```bash
# 扫描所有 session
claude-tap-plus session-collect

# 只扫描指定时间范围
claude-tap-plus session-collect --since 2026-05-01 --until 2026-05-24

# 强制全量重建索引
claude-tap-plus session-collect --rebuild

# 只扫描 trace（不扫 session）
claude-tap-plus session-collect --trace-only

# 详细输出
claude-tap-plus session-collect --verbose
```

**参数：**

| 参数 | 必需 | 说明 |
|------|------|------|
| `--since <date>` | 否 | 起始日期（YYYY-MM-DD），默认全量 |
| `--until <date>` | 否 | 截止日期 |
| `--rebuild` | 否 | 清空索引全量重建 |
| `--trace-only` | 否 | 只扫描 trace 文件 |
| `--session-only` | 否 | 只扫描 session 文件 |
| `--verbose` | 否 | 显示每个文件处理详情 |
| `--dry-run` | 否 | 只统计不写入 |

**输出：**

```text
[session-collect] Scanning ~/.claude/projects/...
[session-collect] Sessions: 142 found, 139 indexed, 3 skipped
[session-collect] Traces:   89 found, 87 indexed, 2 skipped
[session-collect] Associations: 74 strong, 13 weak
[session-collect] Skipped files:
  - a3f2...jsonl: invalid JSON at line 847
  - b7c1...jsonl: empty file
  - session-xxx.jsonl: missing session_id field
[session-collect] Done in 2.3s
```

**幂等规则：**
- 重复执行时，已索引且未修改的文件跳过。
- `--rebuild` 清空后全量重建。
- 无法解析的文件记录到 skipped 表。

#### B.4 `session-find`

按多维度查询 SQLite 索引。

```bash
# 查询所有 session
claude-tap-plus session-find

# 按项目查询
claude-tap-plus session-find --project my-app

# 按机器查询
claude-tap-plus session-find --machine workstation-01

# 按分支查询
claude-tap-plus session-find --branch feature-auth

# 按关键词搜索
claude-tap-plus session-find --keyword "refactor"

# 按来源查询（本地 / 导入）
claude-tap-plus session-find --source import

# 组合查询
claude-tap-plus session-find --project my-app --since 2026-05-01 --branch main

# 指定输出格式
claude-tap-plus session-find --project my-app --format json

# 限制结果数
claude-tap-plus session-find --limit 10 --sort-by date --desc
```

**参数：**

| 参数 | 必需 | 说明 |
|------|------|------|
| `--machine <name>` | 否 | 按机器名筛选 |
| `--project <slug>` | 否 | 按项目 slug 筛选 |
| `--branch <name>` | 否 | 按 Git 分支筛选 |
| `--os <type>` | 否 | 按操作系统筛选（windows / macos / linux） |
| `--slug <text>` | 否 | 按 session slug 筛选 |
| `--session <id>` | 否 | 按精确 session_id 筛选 |
| `--source <type>` | 否 | 按来源筛选（local / import） |
| `--keyword <text>` | 否 | 关键词搜索（匹配 slug、cwd、project） |
| `--since <date>` | 否 | 起始日期 |
| `--until <date>` | 否 | 截止日期 |
| `--has-trace` | 否 | 只显示有 trace 关联的 session |
| `--format <fmt>` | 否 | 输出格式：table（默认）/ json / csv |
| `--limit <n>` | 否 | 结果数量，默认 50 |
| `--sort-by <field>` | 否 | 排序字段：date / project / machine，默认 date |
| `--desc` | 否 | 降序排列（默认升序） |

**输出示例（table）：**

```text
Session ID          Date        Machine         Project    Branch        Source   Traces
──────────────────────────────────────────────────────────────────────────────────────────
a3f2c891...         2026-05-24  workstation-01  my-app     main          local    3
b7c1d4e2...         2026-05-23  laptop-02       my-app     feat-auth     import   1
e9a4f123...         2026-05-22  workstation-01  my-app     fix-bug-42    local    5

3 sessions found.
```

**无结果时：**

```text
No sessions found matching your criteria.

Suggestions:
  - Try broader filters: remove --branch or --since
  - Run `session-collect` to index local sessions
  - Run `session-import` to import from another machine
  - Use `session-find --project my-app` without date filters
```

#### B.5 `session-import`

从外部目录或单个文件导入 trace/session 数据。

```bash

# 指定来源信息
claude-tap-plus session-import --from /path/to/exports/ \
  --source-machine laptop-02 \
  --source-project my-app \
  --source-os macos

# 强制覆盖已有数据
claude-tap-plus session-import --from /path/to/exports/ --force

# 只导入不建索引（后续手动 collect）
claude-tap-plus session-import --from /path/to/exports/ --no-index

# 预览导入内容（不实际写入）
claude-tap-plus session-import --from /path/to/exports/ --dry-run
```

**参数：**

| 参数 | 必需 | 说明 |
|------|------|------|
| `--from <path>` | 是 | 外部目录或 JSONL 文件路径 |
| `--source-machine <name>` | 否 | 来源机器名，默认从文件元数据推断 |
| `--source-project <slug>` | 否 | 来源项目 slug |
| `--source-os <type>` | 否 | 来源操作系统 |
| `--source-branch <name>` | 否 | 来源 Git 分支 |
| `--force` | 否 | 同 session_id 时覆盖（默认跳过） |
| `--no-index` | 否 | 只复制文件，不建索引 |
| `--dry-run` | 否 | 预览模式，不实际写入 |
| `--verbose` | 否 | 显示每个文件处理详情 |

**输出：**

