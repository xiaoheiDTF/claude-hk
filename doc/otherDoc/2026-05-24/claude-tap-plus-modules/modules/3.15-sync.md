# 3.15 Sync 模块

> 来源于 09-module-functional-design.md §3.15、07-sandbox.md、08-current-implementation.md

## 作用

1. 同步 metadata。
2. 导入/导出 trace 和 session。
3. fetch/pull/push sandbox 分支。
4. apply sandbox 修改到主项目。

## 强规则

1. session/metadata 可自动同步。
2. git fetch 可自动执行。
3. sandbox pull/push/apply 必须用户显式触发。
4. 主项目文件不能被 agent 自动修改。

## 功能

### 功能 1：Metadata 同步

同步本地 metadata、session index、trace index。

1. 支持导出到外部存储。
2. 支持从外部导入。
3. 支持增量同步。

### 功能 2：代码同步

以 sandbox 为边界的 Git 同步。

1. fetch — 只拉远端信息，不修改文件内容。
2. pull — 更新 sandbox worktree，需要用户确认。
3. push — 推送 sandbox branch，需要用户显式执行。
4. apply — 从 sandbox 更新主项目，必须先展示 diff 并确认。

### 功能 3：Import/Export

支持跨机器数据迁移。

1. 支持导出 trace、session、metadata 到指定目录。
2. 支持从外部目录导入。
3. 导入数据标记来源。
4. 同 id 默认跳过，防止重复。
