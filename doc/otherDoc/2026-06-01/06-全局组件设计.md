## 顶部导航栏

```
┌─────────────────────────────────────────────────────────────────────────────┐
│  🧠 Claude Tap Plus    │  仪表盘  │  会话  │  Issue  │  信息  │    [⚙️]     │
└─────────────────────────────────────────────────────────────────────────────┘
```

| 导航项 | 对应页面 | 可用 API |
|--------|----------|----------|
| 仪表盘 | `/dashboard` | `GET /health`, `GET /api/sessions`, `GET /api/status`, `GET /api/issues` |
| 会话 | `/sessions` | `GET /api/sessions`, `GET /api/session/{id}`, `GET /api/session/{id}/issues`, `GET /api/session/{id}/tokens`, `GET /api/session/{id}/traces`, `POST /api/session/close` |
| Issue | `/issues` | `GET /api/issues`, `POST /api/issue/check/claim/release/status` |
| 信息 | `/info` | `GET /api/machines`, `GET /api/projects` |
