> 拆分自：`2026-06-01-可视化页面线框图设计-v2.md` §3.2
> 相关参考：[共享参考：API 清单与数据模型](00-共享参考-API清单与数据模型.md)

---

## 可用 API

- `GET /api/sessions?machine_id=xxx&project_slug=xxx&status=xxx` — 列表 + 过滤
- `GET /api/session/{id}` — 详情
- `GET /api/session/{id}/issues` — 会话关联 Issue
- `GET /api/session/{id}/tokens` — Token 统计
- `GET /api/session/{id}/traces` — Trace 文件
- `POST /api/session/close` — 手动关闭
