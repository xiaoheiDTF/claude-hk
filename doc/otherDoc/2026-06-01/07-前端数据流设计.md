## 会话列表页数据流

```
页面加载
    │
    ▼
GET /api/sessions
    │
    ▼
┌─────────────────────────────────────────┐
│ 响应: SessionListResponse               │
│ {                                       │
│   "sessions": [                         │
│     { "session_id": "abc...",           │
│       "machine_id": "user@host-1",      │
│       "project_slug": "project-x",      │
│       "status": "active",               │
│       "registered_at": "..." },         │
│     ...                                 │
│   ]                                     │
│ }                                       │
└─────────────────────────────────────────┘
    │
    ▼
渲染表格
    │
    ▼
用户点击行
    │
    ▼
GET /api/session/{id}
    │
    ▼
渲染详情抽屉（SessionDetail）
```

## Issue 管理页数据流

```
页面加载
    │
    ▼
GET /api/issues?repo=xxx&status=xxx&page=1&page_size=20
    │
    ▼
┌─────────────────────────────────────────┐
│ 响应: IssuesListResponse                │
│ {                                       │
│   "issues": [                           │
│     { "issue_number": 42,               │
│       "repo_full_name": "owner/repo",   │
│       "status": "idle",                 │
│       "session_id": null },             │
│     ...                                 │
│   ],                                    │
│   "total": 42,                          │
│   "page": 1,                            │
│   "page_size": 20,                      │
│   "total_pages": 3                      │
│ }                                       │
└─────────────────────────────────────────┘
    │
    ▼
渲染 Issue 列表 + 分页
    │
    ▼
用户操作（领取/释放/更新状态）
    │
    ▼
POST /api/issue/claim 或 /release 或 /status
    │
    ▼
操作成功后重新查询刷新
```
