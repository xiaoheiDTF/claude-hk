# 机器与项目信息页面 (`/info`)

> 拆分自：`2026-06-01-可视化页面线框图设计-v2.md` §3.4
> 相关参考：[共享参考：API 清单与数据模型](00-共享参考-API清单与数据模型.md)

## 可用数据来源

- `GET /api/machines` — 直接查询机器列表（支持 `?os=`、`?hostname=` 过滤）
- `GET /api/projects` — 直接查询项目列表

---

## 设计思路

通过独立 API 直接获取机器和项目信息。
