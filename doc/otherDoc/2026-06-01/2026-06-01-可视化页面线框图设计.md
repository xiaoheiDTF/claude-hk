# claude-tap-plus 可视化页面线框图设计

> 文档日期：2026-06-01
> 基于后端功能 + Hooks 系统，设计 Web 可视化监控页面的线框图。

---

## 一、设计目标

为 claude-tap-plus 后端设计一套可视化 Web 页面，让使用者可以：

1. **实时监控** — 查看当前活跃的 AI 会话、Issue 处理状态
2. **历史追溯** — 查询过去的会话记录、Issue 流转历史
3. **多维度统计** — 按机器、项目、时间维度查看使用统计
4. **便捷操作** — 手动释放 Issue、查看 Trace 文件等

**设计风格**：深色主题（Dark Mode），类似 GitHub/GitLab 的开发者仪表盘，数据密度高，响应式布局。

### 页面清单

| 页面 | 路径 | 说明 |
|------|------|------|
| **仪表盘** | `/dashboard` | 系统总览，核心指标卡片 + 图表 |
| **Issue 看板** | `/issues` | Issue 状态看板（Kanban 风格） |
| **会话列表** | `/sessions` | 所有会话的列表视图 |
| **机器管理** | `/machines` | 机器列表及详情 |
| **项目管理** | `/projects` | 项目列表及详情 |
| **Trace 查看器** | `/traces` | Trace 文件浏览与搜索 |
| **系统日志** | `/logs` | 后端及 Hook 日志查看 |
| **设置** | `/settings` | 系统配置 |

## 六、交互状态说明

### 6.1 加载状态
- **骨架屏**：页面首次加载时显示灰色占位块
- **Spinner**：按钮操作、数据刷新时显示旋转图标
- **进度条**：大文件上传/下载时显示

### 6.2 空状态
- **无数据**：显示 "暂无数据" + 引导图标
- **无搜索结果**：显示 "未找到匹配项" + 清除筛选按钮
- **无权限**：显示 "需要管理员权限"

### 6.3 错误状态
- **网络错误**：Toast 提示 + 重试按钮
- **API 错误**：红色错误卡片 + 错误码
- **后端离线**：顶部横幅提示 "后端服务不可用"
