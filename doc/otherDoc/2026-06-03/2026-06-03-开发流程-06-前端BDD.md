# 单项目开发流程 — 前端 BDD（Frontend）

> 文档日期：2026-06-03
> 所属系列：单项目开发完整流程
> 阶段定位：前端关注 UI/交互状态，对应 CDD（Component Driven Development）

---

## 一、核心目标

- 前端关注 UI/交互状态：按钮状态、Loading / Success / Error、图标高亮、动画
- 对应 CDD：写组件级测试，保证 UI 和状态行为正确

---

## 二、前端 BDD 模板

```gherkin
Feature: {功能名称} - 前端 UI/交互

  Scenario: {UI 展示场景}
    Given {页面状态}
    When 用户进入 {页面}
    Then 应显示 {UI 元素}

  Scenario: {交互正向场景}
    Given {前置 UI 状态}
    When 用户 {操作}
    Then 应 {UI 变化}
    And 应 {数据更新}

  Scenario: {交互异常场景}
    Given {异常条件}
    When 用户 {操作}
    Then 应显示 {错误提示}
    And 应提供 {补救操作}

  Scenario: {Loading 状态}
    When 用户触发 {操作}
    Then 应显示 Loading 状态
    And {交互元素} 应禁用
```

---

## 三、示例（文章收藏）

```gherkin
Feature: 文章收藏 - 前端 UI/交互

  Scenario: 收藏按钮初始状态
    Given 文章未收藏
    And 用户已登录
    When 用户进入文章详情页
    Then 收藏按钮应为空心星形图标

  Scenario: 点击收藏按钮成功
    Given 文章未收藏
    And 用户已登录
    When 用户点击收藏按钮
    Then 按钮应显示 Loading 状态
    When 收藏请求成功
    Then 图标变为实心黄色星形
    And 显示"收藏成功" Toast

  Scenario: 收藏失败显示错误
    Given 文章未收藏
    And 用户已登录
    When 用户点击收藏按钮
    When 收藏请求返回错误
    Then 图标保持空心
    And 显示错误 Toast "收藏失败，请重试"
    And 收藏按钮可再次点击

  Scenario: 未登录用户点击收藏
    Given 用户未登录
    When 用户点击收藏按钮
    Then 应弹出登录框
```

---

## 四、编写要点

| 要点 | 说明 |
|------|------|
| 关注 UI 状态 | Idle / Loading / Success / Error / Empty |
| 关注交互反馈 | 按钮禁用、图标变化、Toast 提示 |
| 与 Product BDD 对齐 | 每个 Product BDD Then 对应前端 UI 变化 |
| 覆盖异常场景 | 网络错误、空数据、超时 |
