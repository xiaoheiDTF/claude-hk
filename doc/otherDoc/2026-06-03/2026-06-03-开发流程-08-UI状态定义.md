# 单项目开发流程 — UI 状态定义

> 文档日期：2026-06-03
> 所属系列：单项目开发完整流程
> 阶段定位：前端组件的所有状态定义，与 BDD 场景一一对应

---

## 一、核心目标

- 前端组件的所有状态要定义清楚
- 状态与 BDD 场景一致
- 前端自动化测试可以直接复用这些状态

---

## 二、标准状态枚举

每个交互组件至少包含以下状态：

| 状态 | 说明 | 典型表现 |
|------|------|---------|
| Idle | 初始/未操作 | 默认 UI |
| Loading | 用户触发操作中 | 旋转图标、禁用按钮 |
| Success | 操作成功 | 数据展示、成功提示 |
| Error | 操作失败 | 红色提示、重试按钮 |
| Empty | 无数据 | 空状态插画、引导按钮 |

## 四、示例

### 4.1 收藏按钮

| 状态 | 触发条件 | UI 表现 | 对应 BDD Scenario |
|------|---------|--------|------------------|
| Idle（未收藏） | 初始加载 | 空心星形图标，灰色 | 收藏成功 - Given |
| Loading | 点击收藏后 | 图标旋转，禁用点击 | 收藏成功 - When |
| Success（已收藏） | 收藏成功 | 实心星形图标，黄色 | 收藏成功 - Then |
| Error | 收藏失败 | 图标红色，Toast 提示 | 收藏失败 - Then |
| AlreadyFav | 重复点击 | 抖动动画，提示"已收藏" | 重复收藏无效 - Then |

### 4.2 行程生成页

| 状态 | 触发条件 | UI 表现 | 对应 BDD Scenario |
|------|---------|--------|------------------|
| Idle | 初始进入表单页 | 表单正常展示，按钮可点击 | 成功生成 3 天行程 - Given |
| Loading | 点击"生成行程" | 按钮变为 Loading，表单禁用 | 成功生成 3 天行程 - When |
| Success | 行程生成成功 | 展示行程时间轴/地图 | 成功生成 3 天行程 - Then |
| Error | 求解失败 | 显示友好提示 + 替代方案 | 求解失败时给出友好提示 |
| Empty | 结果为空行程 | 空状态插画 + "立即规划"按钮 | 空行程状态 |

## 五、状态管理建议

| 技术 | 适用场景 |
|------|---------|
| 组件内 state | 简单交互（按钮、表单） |
| Pinia / Vuex | 跨组件共享状态 |
| React Query / SWR | 服务端状态管理（自动处理 Loading/Success/Error） |
| XState | 复杂状态机（多步骤流程） |
