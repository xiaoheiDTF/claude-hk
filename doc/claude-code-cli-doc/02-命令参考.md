# 命令参考 - 会话内控制命令

> 来源: https://code.claude.com/docs/zh-CN/commands

Claude Code 中所有可用的 `/` 命令及其使用技巧。

---

## 上下文管理技巧

| 命令 | 用途 |
|------|------|
| `/clear` | 使用空上下文启动新对话。之前的对话在 `/resume` 中保持可用。要在继续同一对话的同时释放上下文，请改用 `/compact` |
| `/compact [instructions]` | 通过总结到目前为止的对话来释放上下文。可选择性地传递焦点说明以进行总结 |
| `/reset` / `/new` | `/clear` 的别名 |
| `/branch [name]` | 在此点创建当前对话的分支。切换到分支并保留原始分支，您可以使用 `/resume` 返回 |
| `/fork` | `/branch` 的别名（当设置 `CLAUDE_CODE_FORK_SUBAGENT` 时，`/fork` 改为生成一个分叉的 subagent） |
| `/rewind` | 将对话和/或代码倒回到上一个点，或从选定的消息进行总结。别名：`/checkpoint`、`/undo` |
| `/export [filename]` | 将当前对话导出为纯文本。使用文件名时，直接写入该文件。不使用文件名时，打开对话框以复制到剪贴板或保存到文件 |

## 模型与性能控制

| 命令 | 用途 |
|------|------|
| `/model [model]` | 选择或更改 AI 模型。不带参数时，打开一个选择器。对于支持的模型，使用左/右箭头调整工作量级别 |
| `/effort [level\|auto]` | 设置模型工作量级别。接受 `low`、`medium`、`high`、`xhigh` 或 `max`。不带参数时，打开交互式滑块 |
| `/fast [on\|off]` | 切换快速模式开启或关闭 |
| `/context` | 将当前上下文使用情况可视化为彩色网格。显示上下文密集型工具、内存膨胀和容量警告的优化建议 |

## 会话管理

| 命令 | 用途 |
|------|------|
| `/resume [session]` | 按 ID 或名称恢复对话，或打开会话选择器。别名：`/continue` |
| `/rename [name]` | 重命名当前会话并在提示栏上显示名称。不使用名称时，从对话历史记录自动生成一个 |
| `/recap` | 按需生成当前会话的单行摘要 |
| `/name`, `-n` | 为会话设置显示名称（启动参数） |
| `/exit` / `/quit` | 退出 CLI |

## 文件与目录操作

| 命令 | 用途 |
|------|------|
| `/add-dir <path>` | 为当前会话期间的文件访问添加工作目录。大多数 `.claude/` 配置不会从添加的目录中发现 |
| `/diff` | 打开交互式差异查看器，显示未提交的更改和每轮差异。使用左/右箭头在当前 git 差异和单个 Claude 轮次之间切换 |
| `/copy [N]` | 将最后一个助手响应复制到剪贴板。传递数字 `N` 以复制第 N 个最新响应。当存在代码块时，显示交互式选择器 |

## 代码审查与质量

| 命令 | 用途 |
|------|------|
| `/review [PR]` | 在当前会话中本地审阅 pull request |
| `/ultrareview [PR]` | 在云沙箱中运行深度、多 agent 代码审阅，使用 ultrareview |
| `/simplify [focus]` | 审阅您最近更改的文件以查找代码重用、质量和效率问题，然后修复它们 |
| `/security-review` | 分析当前分支上的待处理更改以查找安全漏洞 |
| `/autofix-pr [prompt]` | 生成一个网络版 Claude Code 会话，监视当前分支的 PR，并在 CI 失败或审阅者留下评论时推送修复 |

## 批量与自动化操作

| 命令 | 用途 |
|------|------|
| `/batch <instruction>` | 在整个代码库中并行编排大规模更改。研究代码库，将工作分解为 5 到 30 个独立单元，并呈现一个计划 |
| `/loop [interval] [prompt]` | 在会话保持打开状态时重复运行提示。省略间隔，Claude 会在迭代之间自动调整步速。别名：`/proactive` |
| `/schedule [description]` | 创建、更新、列出或运行 routines。别名：`/routines` |
| `/ultraplan <prompt>` | 在 ultraplan 会话中起草计划，在浏览器中审阅，然后远程执行或将其发送回您的终端 |

## 配置与设置

| 命令 | 用途 |
|------|------|
| `/config` / `/settings` | 打开设置界面以调整主题、模型、输出样式和其他偏好设置 |
| `/status` | 打开设置界面（状态选项卡），显示版本、模型、账户和连接性。在 Claude 响应时工作，无需等待当前响应完成 |
| `/theme` | 更改颜色主题。包括 `auto`、浅色、深色、色盲友好主题、ANSI 主题以及自定义主题 |
| `/color [color\|default]` | 为当前会话设置提示栏颜色。可用颜色：`red`、`blue`、`green`、`yellow`、`purple`、`orange`、`pink`、`cyan` |
| `/tui [default\|fullscreen]` | 设置终端 UI 渲染器并使用您的对话完整性重新启动到它。`fullscreen` 启用无闪烁 alt-screen 渲染器 |
| `/focus` | 切换焦点视图，仅显示您的最后一个提示、带有编辑 diffstats 的单行工具调用摘要和最终响应 |
| `/keybindings` | 打开或创建您的快捷键配置文件 |
| `/terminal-setup` | 为 Shift+Enter 和其他快捷键配置终端快捷键 |

## 工具与集成管理

| 命令 | 用途 |
|------|------|
| `/mcp` | 管理 MCP server 连接和 OAuth 身份验证 |
| `/plugin` | 管理 Claude Code plugins |
| `/reload-plugins` | 重新加载所有活跃 plugins 以应用待处理的更改，无需重启 |
| `/hooks` | 查看工具事件的 hook 配置 |
| `/ide` | 管理 IDE 集成并显示状态 |
| `/chrome` | 配置 Claude in Chrome 设置 |
| `/permissions` / `/allowed-tools` | 管理工具权限的允许、询问和拒绝规则 |
| `/skills` | 列出可用的 skills。按 `t` 按令牌计数排序 |
| `/agents` | 管理 agent 配置 |

## 记忆与上下文增强

| 命令 | 用途 |
|------|------|
| `/memory` | 编辑 `CLAUDE.md` 内存文件，启用或禁用 auto-memory，并查看自动内存条目 |
| `/init` | 使用 `CLAUDE.md` 指南初始化项目。设置 `CLAUDE_CODE_NEW_INIT=1` 以获得交互式流程 |
| `/btw <question>` | 提出快速附加问题，无需添加到对话中。侧面问题独立运行，不会中断主要轮次 |

## 诊断与调试

| 命令 | 用途 |
|------|------|
| `/doctor` | 诊断并验证您的 Claude Code 安装和设置。按 `f` 让 Claude 修复任何报告的问题 |
| `/debug [description]` | 为当前会话启用调试日志记录并通过读取会话调试日志来排查问题 |
| `/heapdump` | 将 JavaScript 堆快照和内存分解写入 `~/Desktop`，以诊断高内存使用情况 |
| `/usage` / `/cost` / `/stats` | 显示会话成本、计划使用限制和活动统计 |
| `/feedback [report]` | 提交关于 Claude Code 的反馈。别名：`/bug` |
| `/release-notes` | 在交互式版本选择器中查看更改日志 |

## 远程控制与多平台

| 命令 | 用途 |
|------|------|
| `/remote-control` / `/rc` | 使此会话可从 claude.ai 进行远程控制 |
| `/teleport` / `/tp` | 将网络版 Claude Code 会话拉入此终端 |
| `/desktop` / `/app` | 在 Claude Code Desktop 应用中继续当前会话。仅限 macOS 和 Windows |
| `/mobile` / `/ios` / `/android` | 显示二维码以下载 Claude 移动应用 |
| `/voice [hold\|tap\|off]` | 切换语音听写，或在特定模式下启用它 |

## 团队与协作

| 命令 | 用途 |

| `/team-onboarding` | 从您的 Claude Code 使用历史记录生成团队入职指南 |
| `/install-github-app` | 为存储库设置 Claude GitHub Actions 应用 |
| `/install-slack-app` | 安装 Claude Slack 应用 |
| `/tasks` / `/bashes` | 列出并管理后台任务 |

## 特殊功能命令

| 命令 | 用途 |
|------|------|
| `/plan [description]` | 直接从提示进入 Plan Mode。传递可选描述以进入 Plan Mode 并立即开始该任务 |
| `/claude-api [migrate\|managed-agents-onboard]` | 为您的项目语言加载 Claude API 参考资料。运行 `/claude-api migrate` 以将现有 Claude API 代码升级到更新的模型 |
| `/fewer-permission-prompts` | 扫描您的记录以查找常见的只读 Bash 和 MCP 工具调用，然后向项目 `.claude/settings.json` 添加优先级允许列表以减少权限提示 |
| `/powerup` | 通过带有动画演示的快速交互式课程发现 Claude Code 功能 |
| `/insights` | 生成报告，分析您的 Claude Code 会话，包括项目领域、交互模式和摩擦点 |
| `/sandbox` | 切换 sandbox mode。仅在支持的平台上可用 |
| `/statusline` | 配置 Claude Code 的状态行 |
| `/login` / `/logout` | 登录/登出您的 Anthropic 账户 |
| `/upgrade` | 打开升级页面以切换到更高的计划层级 |
| `/extra-usage` | 配置额外使用量以在达到速率限制时继续工作 |
| `/privacy-settings` | 查看和更新您的隐私设置。仅对 Pro 和 Max 计划订阅者可用 |
| `/setup-bedrock` | 通过交互式向导配置 Amazon Bedrock 身份验证、区域和模型固定 |
| `/setup-vertex` | 通过交互式向导配置 Google Vertex AI 身份验证、项目、区域和模型固定 |
| `/web-setup` | 使用您的本地 `gh` CLI 凭证将您的 GitHub 账户连接到网络版 Claude Code |
| `/remote-env` | 为使用 `--remote` 启动的网络会话配置默认远程环境 |
| `/stickers` | 订购 Claude Code 贴纸 |
